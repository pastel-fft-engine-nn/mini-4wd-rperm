よくあること

  • 回転が -- のまま … マイクを近づける。TH（ノイズ閾値）が高すぎないか見る。
  • 数字が跳ぶ … 集音範囲を狭める。周囲の音を減らす。
  • 許可を出した覚えがない … iOS の設定 → RPM Memory → マイク。
  • 値は推定です。公式回転計の代替ではありません。
