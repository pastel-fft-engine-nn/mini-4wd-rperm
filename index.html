使い方

RPM Memory はモーター音の高さから回転数を推定する測定アプリです。値は推定と机上計算です。公式回転計の代替ではありません。下の項目は、閉じたまま並んでいます。知りたい名前を押すと開きます。

上から順に、画面に出ているものの意味です。

RPM MEMORY

アプリの名前です。押しても何も起きません。

スペクトラム

マイクが今聞いている音を、横の山で表します。山が高いほど、その高さの音が強いです。回転の数字は、この山から出しています。

マイクの棒と READY

マイクが入っているかの印です。READY はまだ測っていない状態です。計測を始めると MEASURING — 解析中 に変わります。

MOTOR RPM

モーター回転の推定です。CURRENT が今の値、MAX がこの計測でいちばん高かった値、MIN がいちばん低かった値です。枠を押すと目標を入れられます。詳しくは「目標回転」。

SPEED (km/h)

その回転から計算した机上の速度です。CURRENT が今、TOP がこの計測の最高、MIN が最低です。実走の速度計ではありません。計算の中身は「速度が机上値である理由」。

状態の文字

数字の下の READY や MEASURING は、今が待機か計測中かを示す一行です。

Top of the screen: the spectrum is the live sound, MOTOR RPM is the estimate (current / max / min), SPEED is a desk calculation, not a track speed.

計測開始 / 計測停止

計測開始でマイクを使い始めます。最初の一回だけ、マイクの許可を聞かれます。許可しないと数字は出ません。押したあとは計測停止になり、もう一度押すとマイクをやめます。

ロック

今の数字をその場で固定します。保存ではありません。比較表は、ロックした回転を起点にします。もう一度押すと解除です。ロックした瞬間の時刻・回転・モーター・ギヤ・電圧・タイヤ径は、マシン設定の「ロック履歴」に残ります。

保存

記録をこの端末の履歴に残します。残るのは、その計測の最高回転が基本です。保存モードが「毎回名前を聞いて保存」なら名前を聞きます。「前回の名前で上書き確認」なら、前回の名前で上書きしていいかを聞きます。

Start uses the mic. Lock freezes the number for the chart. Save writes a record on this device only.

大きなボタンではありません。左から順です。

リセット

マシン設定

駆動、モーター、電圧、ギヤ比、タイヤ径を入れます。詳しくは「マシン設定の項目」。

逆算

モーターは回転すると、回転に比例した周波数の音を出します。マイクでその音を取り込み、強い山の周波数を RPM に換算します。

RPM ＝ 周波数(Hz) × 60。例: 400Hz なら 24,000 rpm。

実機の音にはギア音・ブラシ音・走行音・声が混ざります。アプリは集音窓の中で一番強い山を見るので、別の音が山になると数字が飛びます。

  • 電圧・ギヤ・タイヤを今の車両に近づける
  • 集音範囲を想定回転に合わせる
  • 計測開始（ここでマイク許可）
  • マイクをモーターへ近づける
  • 数字が数秒安定したらロック
  • 必要なら保存

CURRENT は今の推定。MAX / MIN はこの計測中の最高と最低。SPEED は机上換算で、実走速度ではありません。

ロックは数字を固定する操作で、保存ではありません。リセットはトップの CURRENT・MAX・MIN と速度だけ消します。設定、マシン設定、比較表、ロック、履歴はそのままです。

グラフの横点線と「TH 40」が Threshold（閾値）です。スライダー目盛り 20 の2倍が、この線の高さです。目盛りを 1 動かすと、線は 2 上がります。

  • 線より上の山だけを回転の候補にする
  • 線より下の小さな揺れは使わない
  • 山の頂点が TH を超えなければ表示は --

TH は「この高さ未満は騒音とみなす」線です。集音フィルタ（回転の上下限）とは別です。

  • 集音フィルタ … どの回転帯を見るか（左右）
  • TH … どれだけ強い山だけを採用するか（上下）

両方を同時に使います。窓を狭めても TH が低ければ、その窓の中の小さなノイズを拾います。TH を上げても窓が広ければ、別の強い音に飛びます。

見るタイミング: 数字が飛ぶ、消える、山がいくつもあるとき。線と山の位置を先に見てください。

周波数ごとの強さに対する採用ラインです。スライダーは 0〜100 を 1 刻み。初期の目盛りは 20 で、線の高さは 40 です。21 なら線は 42。表示の数字は線の高さです。

上げるとき: 声・空調・他車・机の振動を切りたい。代償としてモーター自身も拾いにくくなる。少し離しただけ、電圧が落ちて音が細くなっただけで -- になりやすい。「測れているのに急に消える」は TH が高すぎることが多い。

下げるとき: 弱いモーター音でも数字を出したい。代償として無関係な音でも山になり、回転が跳ぶ・倍になる・測っていないのに動く。

合わせ方:

  • モーターを止めて計測を始める
  • 小さなギザギザだけなら、その少し上に TH を置く
  • 回して、山が TH をはっきり超えるか見る
  • 超えないときは、閾値を下げるより先にマイクを近づける。それでも弱いときだけ下げる

サーキットで上げたくなったら、集音範囲も同時に狭めてください。閾値だけ上げると自分のモーターまで消えます。自宅の静かな机なら目盛り 20（線は 40）のままで足りることが多いです。暴れるときだけ動かし、リセットで目盛り 20 に戻ります。

線が上にあるほど厳しい、下にあるほど甘い。山が線から少し出る程度が扱いやすいです。山が線に埋まっているなら上げすぎ、線の近くに小さな山がいくつもあるなら下げすぎか窓が広いです。

音から出した回転に掛ける倍率です。初期値 1.00、範囲 0.50〜1.50。
表示のもと ＝ 周波数から出した回転 × 校正係数。

使うとき: この端末・この測り方で、いつも同じ方向にずれると分かったときだけ。普段は 1.00 のまま。モーターの性能そのものではありません。

  • 光学式などで 30,000 と分かっているのに 28,500 と出る → 30000 ÷ 28500 ≒ 1.05
  • いつも高く出る → 0.95 など

1回のずれでは合わせないでください。距離や電圧を変えても同じ比率か見てから動かします。友人の記録や以前の履歴と混ぜるなら、係数を揃えるかすべて 1.00 に戻します。

負荷と同時に動かすと原因が分からなくなります。校正を触るときは負荷を 0% にしてください。リセットで 1.00。普段は触らない設定です。

無負荷で測った回転を、車載の落ち込みに近づける見積もりです。初期値 0%、範囲 −100〜+100。
負荷後の回転 ＝ 校正後の回転 × (1 − 走行負荷%/100)。速度も同じ比率です。

校正 1.00 のとき、30,000 rpm は 0% で 30,000、+10% で 27,000、+20% で 24,000、−10% で 33,000 と出ます。プラスにすると画面の回転と机上速度は小さくなります。「走行中はこれくらい落ちるだろう」という仮定です。

シャーシの実ロス、タイヤの潰れ、ギヤの噛み、コーナー、接地、電圧降下は自動では入りません。20% にしたから実走が 20% 遅くなる、という意味ではありません。

使うとき: 机上の単体測定は 0%。車に載せて落ちる分を記録に残したいときだけ、10〜20% などを試し、生の値も見てください。分からなければ 0% のまま生の値で比較するのが誤解が少ないです。

「負荷適用値を並べて表示」をオンにすると、主表示が負荷後、小さく生の値が出ます。履歴にも負荷%が残るので、あとで比べるときは % を揃えるか生 RPM で揃えてください。

マイナス%は表示を上げます。校正の代わりに使わないでください。校正は端末のずれ、負荷は走行の見積もりです。主表示・MAX / MIN・ロック・比較表は負荷後基準です。議論するときは「負荷何%の値か」を先に確認してください。リセットで 0% です。

  • ノイズ閾値 / TH … どの強さの山を回転と認めるか。普段は目盛り 20（線は 40）。暴れる・消えるときだけ
  • RPM校正係数 … 測定値全体の倍率。普段は 1.00。基準があるときだけ
  • 走行負荷 … 車載で落ちると仮定して表示を落とす。普段は 0%。記録のメモ用

先に測る条件を揃える（距離、電圧、無負荷か車載か）方が、スライダーをいじるより効きます。数値はどれも推定と机上計算です。

速度(km/h) ＝ (モーターrpm ÷ ギヤ比) × タイヤ径(mm) × (π × 60 / 1,000,000)

モーター回転をギヤで軸回転に直し、タイヤ円周で進む距離にしています。スリップ、接地、ロス、電圧降下、発熱は入っていません。実走より速く出ることがほとんどです。

電圧は式に直接入りません。測った電源のメモと比較表の列分けに使います。

比較表の上の数字はロスなしです。片軸か両軸のとき、下の括弧だけが伝達込みの仮定です。トップの SPEED はロスなしのままです。公式の摩擦値はありません。詳しくは「伝達ロスの仮定」。

比較表の上の km/h はロスなしです。括弧の中だけ、駆動ごとの残り割合を掛けています。トップの SPEED と回転数は変えません。測った音には、すでにその場の摩擦が入っていることがあります。そこへさらに掛けると、二重に引くことになります。

両軸は 98% です。以前の 97% と 97.5%、走行負荷 6% と同じ 94% は、いま計算に使っていません。

片軸は 87.5% です。98% に、以前の 86.6 ÷ 97 を掛けています。

これは公式の測定値ではありません。グリス、傾き、トルクで変わります。効率は本来、速度ではなくトルクと動力の残りです。同じ割合で速度が落ちるとは限りません。見比べ用の仮定です。駆動が未選択のときは 100% で、掛けません。

マシン設定は、今の車のメモです。駆動、シャーシ、モーター、保存モード、ロック履歴はここだけです。シャーシを選ぶと駆動と使えるギヤが揃います。速度の主表示には伝達を掛けません。括弧だけが仮定です。「反映して閉じる」と、電圧・ギヤ比・タイヤ径が比較表の計算にコピーされます。その入力欄はトップには出しません。

比較表の上に、駆動・モーター・電圧・ギヤ・タイヤが出ます。片軸か両軸かで、使えるギヤの列が違います。薄い列は、今の駆動では使わないギヤです。選んだ電圧の行と、選んだギヤの列が強調されます。

Machine settings copy voltage, gear and tire into the table. The top page no longer shows those inputs. Pale columns are gears that shaft does not use.

電圧・ギヤ比・タイヤ径は、マシン設定で入れて比較表に反映します。トップには入力欄を出していません。比較表そのものは、ロックしたあとでないと中身が出ません。

比較表はロックした回転を起点にした仮定です。ギヤを変えると実回転も変わるので、「このギヤなら必ずこの速度」ではありません。別の電圧の行は、回転が電圧に比例するとして並べています。実際はおおむね比例しますが、完全ではありません。

履歴はこの端末に残ります。クラウド同期はありません。比べるときは電圧・ギヤ・負荷%を揃えるか、生RPMで見てください。

逆算は速度計算の逆です。求めたいものを選んで使います。

  • 速度 km/h … 回転・ギヤ・タイヤから机上速度
  • 必要なタイヤ径 mm … 目標の速度になる径
  • 必要なモーター回転数 rpm … 目標の速度になる回転
  • 必要なギヤ比 … 目標の速度になるギヤ

どれもロスなしの理論値です。実走の答えではありません。

  • 数字が出ない → マイク許可、計測開始、モーターが回っているか
  • 暴れる → 窓が広い、TH が低い、周囲がうるさい
  • 低すぎ / 高すぎ → 倍音、窓の位置、校正が残っている
  • 速度だけおかしい → ギヤとタイヤが実車と違う
  • 比較表が空 → まだロックしていない

マイク許可: モーター音の周波数から回転数（RPM）を測定するためにマイクを使います。音声は端末内だけで処理し、サーバーへ送信しません。
