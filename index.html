使い方

RPM Memory はモーター音の高さから回転数を推定する測定アプリです。値は推定と机上計算です。公式回転計の代替ではありません。下の項目は、閉じたまま並んでいます。知りたい名前を押すと、その場で開きます。

上から順に、画面に出ているものの意味です。

RPM MEMORY

アプリの名前です。押しても何も起きません。

スペクトラム

マイクが今聞いている音を、横の山で表します。山が高いほど、その高さの音が強いです。回転の数字は、この山から出しています。

マイクの棒と READY

マイクが入っているかの印です。READY はまだ測っていない状態です。計測を始めると MEASURING — 解析中 に変わります。

MOTOR RPM

モーター回転の推定です。CURRENT が今の値、そのすぐ下の AVG が安定しているあいだの平均です。MAX がこの計測でいちばん高かった値、MIN がいちばん低かった値です。設定で「安定してから数える」がオンなら、MAX・MIN・AVG は 8000rpm 以上が 0.6秒続いたあとからです。枠を押すと目標を入れられます。

SPEED (km/h)

その回転から計算した机上の速度です。CURRENT のすぐ下の AVG が、同じ区間の平均速度です。MAX がこの計測の最高、MIN が最低です。安定してから数えるがオンなら、MAX・MIN・AVG も立ち上がりを入れません。実走の速度計ではありません。

状態の文字

数字の下の READY や MEASURING は、今が待機か計測中かを示す一行です。

Top of the screen: the spectrum is the live sound, MOTOR RPM is the estimate (current / max / min), SPEED is a desk calculation, not a track speed.

計測開始 / 計測停止

計測開始でマイクを使い始めます。最初の一回だけ、マイクの許可を聞かれます。許可しないと数字は出ません。押したあとは計測停止になり、もう一度押すとマイクをやめます。

ロック

今の数字をその場で固定します。保存ではありません。比較表は、ロックした回転を起点にします。もう一度押すと解除です。ロックした瞬間の日付（月/日）・回転・モーター・ギヤ・電圧・タイヤ径は、マシン設定の「ロック履歴」に残ります。

保存

記録をこの端末の履歴に残します。残るのは、その計測の最高回転が基本です。保存モードが「毎回名前を聞いて保存」なら名前を聞きます。「前回の名前で上書き確認」なら、前回の名前で上書きしていいかを聞きます。

タイヤ付（駆動ロス）

このアプリは本来、モーター単体の音を拾って回転数を測るものです。タイヤ付はおまけの機能で、ギヤやタイヤを組み付けた状態では単体からどれくらい回転数が落ちるのか、その割合（駆動ロス）を % で見るために使います。

流れは、単体で測る → 「タイヤ付」ボタンを押す → 組み付けて測る → 落ちた割合が % で出る、です。ボタンを押すと、その時点の回転数を「単体」として取り込み、単体・タイヤ付・駆動ロス（落ちた割合 %）の帯が出て、ボタンが黄色く点灯します。タイヤ付の値は計測に合わせて動き、ロックするとその値で止まります。もう一度ボタンを押すと帯が消えます。

「単体」の値は端末に残るので、組み直している間に画面を閉じても、続きから測れます。取り直したいときは、帯に出ている「単体」の表示を押してください。そのとき画面に出ている回転数が、新しい「単体」として控え直されます。

帯が出ている状態で保存すると、単体・タイヤ付・ロス%も履歴に残ります。履歴のカードの「この記録でタイヤ付計測」を押すと、その記録の値（単体値がある記録は単体値、ない記録はRPM）が単体の基準になって帯が開きます。たとえば、慣らしをする前の記録を単体にして、今の落ち具合と比べることができます。単体のラベルに出典の日付と電圧が出て、保存すると新しい記録に出典も残ります。その状態で保存画面を開くと「元の記録に追加する」のチェックが出ます。チェックを入れて保存すると、新規登録せず、元の記録にタイヤ付・ロス%が追加されます。

なお、タイヤを空転させたときの負荷は駆動系の抵抗だけなので、実走の負荷とは別物です。また、組み付けた状態はモーター音が拾いにくくなることがあります。数値が大きく跳ねる場合は、集音フィルタの範囲を狭めると安定します。タイヤ付は、どの外観でもボタンと帯が出ます。

A/B比較

「基準」を1つ決めておいて、いまの回転数がそれより何 % 高いか・低いかを見続けるための機能です。下の文字の並びにある「A/B比較」を押すと、基準・今・差の帯が出ます。もう一度押すと帯が消えます。タイヤ付の帯とは同時には出ません（片方を開くと、もう片方は閉じます）。A/B比較も、どの外観でも下のほうにボタンと帯が出ます（中身は標準画面と同じです）。

使い方です。（1）基準にしたい状態で測ります。（2）帯の「基準」の表示を押すと、そのとき画面に出ている回転数が基準として控えられ、名前を聞かれるので付けます（例：慣らし前、ギヤ交換前）。（3）条件を変えて測ると、「今」がいまの回転数、「差」が基準との差 %（今 ÷ 基準 − 1）で動き続けます。プラスなら基準より高く、マイナスなら低く回っています。名前だけ変えたいときは、帯の名前のボタンを押します。基準は端末に残るので、帯を閉じて開き直しても続きから比べられます。

何に使うか：慣らしの前後、ギヤやタイヤを換える前後、電池を変えたときなど、「前と比べてどう変わったか」をその場で見るためのものです。タイヤ付が「単体 → 組み付け」専用の比べ方なのに対して、A/B は比べる相手を自由に決められます。過去の記録と比べたいときは、履歴のカードの「この記録と比較」を押すと、その記録の RPM が基準になって帯が開きます（名前は「M/Dの記録・x.xV」と自動で付きます）。

帯が出ている状態で保存すると、基準・今・差%・基準名も履歴に残り、カードの下の段に出ます。注意として、基準と今とで電圧やギヤ・負荷%が違うと、その違いも差 % に混ざります。比べたいもの以外は条件を揃えてください。

Start uses the mic. Lock freezes the number for the chart. Save writes a record on this device only. Tire compares a motor-only reading with the assembled car and shows the drive loss %. If readings jump when assembled, narrow the mic filter band. A/B keeps one named baseline RPM and shows the live difference % against it.

大きなボタンではありません。左から順です。

履歴

保存した記録の一覧を開きます。詳しくは「履歴の画面」。

リセット

今画面に出ている CURRENT、MAX、MIN、AVG と速度だけを消します。履歴は消えません。計測の途中なら、計測自体は続きます。ロック中ならロックも外れます。

マシン設定

駆動、モーター、電圧、ギヤ比、タイヤ径を入れます。詳しくは「マシン設定の項目」。

逆算

速度、回転、ギヤ、タイヤのどれか一つを、残りの数字から計算します。詳しくは「比較表・履歴・逆算」。

設定

ノイズ閾値、校正、負荷、外観、言語、ダークを変えます。この使い方も、設定の中から開きます。トップには使い方のボタンはありません。

The text row is history, reset, machine, reverse calc, and settings. Reset clears only the live numbers.

CURRENT のすぐ下にある AVG は、この計測で安定して回っていたあいだの平均です。コースを走った実平均ではありません。平均値は、回してから計測開始を押してください。もしくは、回してるときにリセットを押してください。

AVG の横に出る「変動 x.x%」が回転の安定度です。平均を取っているあいだの回転数のばらつき（標準偏差 ÷ 平均）で、小さいほど安定して回っています。ブレや振動、当たりの悪さの目安になります。保存すると履歴にも残り、記録カードの平均の所に出ます。

設定の「安定してから MAX / MIN / AVG を数える」がオンのときは、CURRENT だけすぐ動きます。MAX・MIN・AVG は、8000rpm 以上が 0.6秒続いたあとから記録します。立ち上がりの低い数字は、トップにもミニマムにも入りません。オフにすると、数字が出た瞬間から MAX・MIN を記録します。選んだ状態は残ります。最初はオンです。

  • 8000rpm 未満は入れない。電源を入れた直後の低い回転を外すため
  • 急に上がっているあいだも入れない。計測開始が先でも、電源が先でも、立ち上がりは両方とも外す
  • 落ち着いてから 0.6 秒たって数え始め、合計 1 秒以上で数字を出す。それまでは --
  • 音が途切れて -- のあいだは平均に足さない
  • ロックすると止まる。停止しても値は残るので、そのあと保存できる
  • 次の計測開始とリセットで消える

履歴のカードでは、1行目の右に RPM AVG、2行目の右に速度 AVG として残ります。

AVG is the stable part of this run only. Spin-up and gaps are left out. It is not a lap average.

マシン設定の「設定のお気に入り」です。今の車の条件を、名前つきでまとめて残せます。

  • 「この設定を登録」を押すと名前を聞かれる。それがお気に入りの名前になる
  • この設定を登録、で残る。駆動、シャーシ、モーター、電圧、ギヤ、タイヤ、閾値、集音範囲、負荷、校正
  • 名前を押すと、その一式に戻る
  • 削除で、その登録だけ消える。履歴の記録は消えない
  • この端末の中だけに残る。最大 12 件

Setup favorites store the whole machine and measure setup under the record name. Tap a name to restore it.

  • この計測の MAX が 30,000 以上になると、MAX だけ赤くなり、枠が付く

目標はこの端末に残ります。アプリを閉じても、次に開いたとき同じ数字です。測る前の目印なので、回転そのものの計算は変えません。

Tap the MOTOR RPM block to set a target. Only MAX turns red when it reaches that number.

スペクトラムの下にある、左右の丸いつまみです。左が下限、右が上限です。最初は 5,000 から 50,000 です。

The two knobs set the RPM window. Sounds outside it are ignored. This is separate from the TH line.

駆動

指定なし、両軸、片軸。モーターの候補が変わります。指定なしのままなら、両方のモーターから選べます。

シャーシ

選べます。両軸は ME・MA・MS、片軸は FM-A からタイプ1までです。選ぶと駆動が揃い、そのシャーシのギヤだけが残ります。名前だけでは、速度に別のロスは足しません。

モーター

今載せている種類です。履歴やロック履歴では短い名前になります。例: ノーマルPRO は NMP、マッハPRO は MDP。

電圧

電池の目安です。トップで測る回転と速度の式には直接入りません（測った回転がそのまま出ます）。記録と比較のときのメモと、マシン設定の中や逆算での机上換算に使います。枠に直接、小数第2位まで入れられます。ボタンは −0.01 / −0.1 / ＋0.1 / ＋0.01 の4つで、範囲は 2.2〜3.5V です。育成の電力計算では、この電圧を使います。

育成の電圧とアンペア

電圧の下にあります。アプリでの位置づけは次のとおりです。

  • 電圧はスピードの上限です。マシン設定の電圧を上げると、机上換算の回転（マシン設定の中の見本や逆算の数字）もその比で上がります。トップで測っている回転そのものは変わりません
  • 抵抗は机上で出します。電圧 ÷ 電流です。2.8 V ÷ 5.0 A なら 0.56 Ω です。モーターの特性と、摩擦や負荷をまとめた邪魔もの、という扱いです
  • 電流は結果です。モーターが持つ固定の数字ではなく、負荷に合わせて電池から引く量です。空回しは低く、走行や坂では上がります

机上の動きです。1.0 A を軽い負荷の基準にしています。電流がそれより増えると、負荷が重いとみなして、机上の回転と速度を下げます。電圧が上がれば、上限が上がるので机上回転は上がります。

測定したRPMは音のままです。アンペアを変えても音は変わりません。変わるのは机上の数字だけです。電力（電圧 × 電流）の表示はそのまま残しています。速度の係数には使っていません。

  • チェックがオフのときは畳んでいます。オフの係数は 1.00 で、オンにして 1.0A にしたときと同じです
  • チェックを入れると開きます。電流は 0.1A から 5.0A までのスライダーです
  • 測定RPMが出ると、電圧±0.2と電流±0.5の机上RPMも出ます
  • 「抵抗を計算に使う」をオンにすると、スライダーで抵抗を好みの値にできます。横の？に、モーターごとの目安をしまってあります。オフのときは使いません。アンペアも抵抗もオフなら、音のRPMと、それに合う速度だけです。反映して閉じると、今の係数が速度に入ります。選んだ状態は残ります

Amp is a desk factor for speed only. RPM stays the sound reading. Off equals 1.0A on. Changing the amp does not change the sound.

ギヤ比

速度の計算に使います。モーター回転を、車軸の回転に直す比率です。

タイヤ径

モーターは回転すると、回転に比例した周波数の音を出します。マイクでその音を取り込み、強い山の周波数を RPM に換算します。

RPM ＝ 周波数(Hz) × 60。例: 400Hz なら 24,000 rpm。

実機の音にはギア音・ブラシ音・走行音・声が混ざります。アプリは集音窓の中で一番強い山を見るので、別の音が山になると数字が飛びます。

  • 電圧・ギヤ・タイヤを今の車両に近づける
  • 集音範囲を想定回転に合わせる
  • 計測開始（ここでマイク許可）
  • マイクをモーターへ近づける
  • 数字が数秒安定したらロック
  • 必要なら保存

CURRENT は今の推定。MAX / MIN はこの計測中の最高と最低。SPEED は机上換算で、実走速度ではありません。

ロックは数字を固定する操作で、保存ではありません。リセットはトップの CURRENT・MAX・MIN と速度を消します。ロック中ならロックも外れて、比較表も消えます。設定、マシン設定、履歴はそのままです。

グラフの横点線と「TH 20」が Threshold（閾値）です。スライダーの目盛りが、そのまま線の高さです。初期値は 20 です。

  • 線より上の山だけを回転の候補にする
  • 線より下の小さな揺れは使わない
  • 山の頂点が TH を超えなければ表示は --

TH は「この高さ未満は騒音とみなす」線です。集音フィルタ（回転の上下限）とは別です。

  • 集音フィルタ … どの回転帯を見るか（左右）
  • TH … どれだけ強い山だけを採用するか（上下）

両方を同時に使います。窓を狭めても TH が低ければ、その窓の中の小さなノイズを拾います。TH を上げても窓が広ければ、別の強い音に飛びます。

見るタイミング: 数字が飛ぶ、消える、山がいくつもあるとき。線と山の位置を先に見てください。

周波数ごとの強さに対する採用ラインです。スライダーは 0〜100 を 1 刻み。初期値は 20 で、線の高さも 20 です。表示の数字が線の高さです。

上げるとき: 声・空調・他車・机の振動を切りたい。代償としてモーター自身も拾いにくくなる。少し離しただけ、電圧が落ちて音が細くなっただけで -- になりやすい。「測れているのに急に消える」は TH が高すぎることが多い。

下げるとき: 弱いモーター音でも数字を出したい。代償として無関係な音でも山になり、回転が跳ぶ・倍になる・測っていないのに動く。

合わせ方:

  • モーターを止めて計測を始める
  • 小さなギザギザだけなら、その少し上に TH を置く
  • 回して、山が TH をはっきり超えるか見る
  • 超えないときは、閾値を下げるより先にマイクを近づける。それでも弱いときだけ下げる

サーキットで上げたくなったら、集音範囲も同時に狭めてください。閾値だけ上げると自分のモーターまで消えます。自宅の静かな机なら 20 のままで足りることが多いです。暴れるときだけ動かし、リセットで目盛り 20 に戻ります。

線が上にあるほど厳しい、下にあるほど甘い。山が線から少し出る程度が扱いやすいです。山が線に埋まっているなら上げすぎ、線の近くに小さな山がいくつもあるなら下げすぎか窓が広いです。

音から出した回転に掛ける倍率です。初期値 1.00、範囲 0.50〜1.50。
表示のもと ＝ 周波数から出した回転 × 校正係数。

使うとき: この端末・この測り方で、いつも同じ方向にずれると分かったときだけ。普段は 1.00 のまま。モーターの性能そのものではありません。

  • 光学式などで 30,000 と分かっているのに 28,500 と出る → 30000 ÷ 28500 ≒ 1.05
  • いつも高く出る → 0.95 など

1回のずれでは合わせないでください。距離や電圧を変えても同じ比率か見てから動かします。友人の記録や以前の履歴と混ぜるなら、係数を揃えるかすべて 1.00 に戻します。

負荷と同時に動かすと原因が分からなくなります。校正を触るときは負荷を 0% にしてください。リセットで 1.00。普段は触らない設定です。

無負荷で測った回転を、車載の落ち込みに近づける見積もりです。初期値 0%、範囲 −100〜+100。
負荷後の回転 ＝ 校正後の回転 × (1 − 走行負荷%/100)。速度も同じ比率です。

校正 1.00 のとき、30,000 rpm は 0% で 30,000、+10% で 27,000、+20% で 24,000、−10% で 33,000 と出ます。プラスにすると画面の回転と机上速度は小さくなります。「走行中はこれくらい落ちるだろう」という仮定です。

シャーシの実ロス、タイヤの潰れ、ギヤの噛み、コーナー、接地、電圧降下は自動では入りません。20% にしたから実走が 20% 遅くなる、という意味ではありません。

使うとき: 机上の単体測定は 0%。車に載せて落ちる分を記録に残したいときだけ、10〜20% などを試し、生の値も見てください。分からなければ 0% のまま生の値で比較するのが誤解が少ないです。

「負荷適用値を並べて表示」をオンにすると、主表示が負荷後、小さく生の値が出ます。履歴にも負荷%が残るので、あとで比べるときは % を揃えるか生 RPM で揃えてください。

マイナス%は表示を上げます。校正の代わりに使わないでください。校正は端末のずれ、負荷は走行の見積もりです。主表示・MAX / MIN・ロック・比較表は負荷後基準です。議論するときは「負荷何%の値か」を先に確認してください。リセットで 0% です。

  • ノイズ閾値 / TH … どの強さの山を回転と認めるか。普段は 20。暴れる・消えるときだけ
  • RPM校正係数 … 測定値全体の倍率。普段は 1.00。基準があるときだけ
  • 走行負荷 … 車載で落ちると仮定して表示を落とす。普段は 0%。記録のメモ用

先に測る条件を揃える（距離、電圧、無負荷か車載か）方が、スライダーをいじるより効きます。数値はどれも推定と机上計算です。

速度(km/h) ＝ (モーターrpm ÷ ギヤ比) × タイヤ径(mm) × (π × 60 / 1,000,000)

モーター回転をギヤで軸回転に直し、タイヤ円周で進む距離にしています。スリップ、接地、ロス、電圧降下、発熱は入っていません。実走より速く出ることがほとんどです。

電圧は式に直接入りません。測った電源のメモと比較表の列分けに使います。

比較表の上の数字はロスなしです。片軸か両軸のとき、下の括弧だけが伝達込みの仮定です。トップの SPEED はロスなしのままです。公式の摩擦値はありません。詳しくは「伝達ロスの仮定」。

比較表の上の km/h はロスなしです。括弧の中だけ、駆動ごとの残り割合を掛けています。トップの SPEED と回転数は変えません。測った音には、すでにその場の摩擦が入っていることがあります。そこへさらに掛けると、二重に引くことになります。

両軸は 98% です。

片軸は 87.5% です。98% に、以前の 86.6 ÷ 97 を掛けています。

これは公式の測定値ではありません。グリス、傾き、トルクで変わります。効率は本来、速度ではなくトルクと動力の残りです。同じ割合で速度が落ちるとは限りません。見比べ用の仮定です。駆動が未選択のときは 100% で、掛けません。

マシン設定は、今の車のメモです。駆動、シャーシ、モーター、保存モード、ロック履歴はここだけです。シャーシを選ぶと駆動と使えるギヤが揃います。速度の主表示には伝達を掛けません。括弧だけが仮定です。電圧・ギヤ比・タイヤ径は、入力した時点でトップと比較表の計算に同期されます。その入力欄はトップには出しません。

比較表の上に、駆動・モーター・電圧・ギヤ・タイヤが出ます。片軸か両軸かで、使えるギヤの列が違います。薄い列は、今の駆動では使わないギヤです。選んだ電圧の行と、選んだギヤの列が強調されます。

Machine settings copy voltage, gear and tire into the table. The top page no longer shows those inputs. Pale columns are gears that shaft does not use.

電圧・ギヤ比・タイヤ径は、マシン設定で入れて比較表に反映します。トップには入力欄を出していません。比較表そのものは、ロックしたあとでないと中身が出ません。

比較表はロックした回転を起点にした仮定です。ギヤを変えると実回転も変わるので、「このギヤなら必ずこの速度」ではありません。別の電圧の行は、回転が電圧に比例するとして並べています。実際はおおむね比例しますが、完全ではありません。

履歴はこの端末に残ります。クラウド同期はありません。比べるときは電圧・ギヤ・負荷%を揃えるか、生RPMで見てください。

逆算は速度計算の逆です。求めたいものを選んで使います。

  • 速度 km/h … 回転・ギヤ・タイヤから机上速度
  • 必要なタイヤ径 mm … 目標の速度になる径
  • 必要なモーター回転数 rpm … 目標の速度になる回転
  • 必要なギヤ比 … 目標の速度になるギヤ
  • 必要トルク mN・m … 坂を一定速度で登るのに必要なモータートルク
  • ジャンプ（飛距離） … 坂を登った先の飛距離の見積もり
  • ギヤ×タイヤ一覧表 … 今の回転数・電圧のまま、ギヤ比とタイヤ径の全組み合わせの机上速度を表にしたもの。セルを押すと、そのギヤとタイヤが入力にセットされます。電圧を変えた速度の並びを見たいときは、ロックしたときの電圧別比較表の方が向いています

ギヤ×タイヤ一覧表

逆算で「ギヤ×タイヤ一覧表」を選ぶと出ます。縦がギヤ比（8種）、横がタイヤ径（21.0〜28.0mm、0.5mm刻み）で、セル1つ1つが、その組み合わせでの机上速度です。もとになる回転数は逆算の「モーター回転数」の欄、電圧は逆算の電圧（アンペア・抵抗の補正込み）です。今選んでいるギヤとタイヤのセルは色が付いていて、画面の大きな数字もその組み合わせの速度です。表は横にスクロールできます。

セルを押すと、そのギヤ比とタイヤ径が逆算の入力にセットされます（試し計算を切り替えるためで、マシン設定や実際の車は変わりません）。例：28,000rpm・電圧そのままでは、3.7:1／22.5mm が 32.1 km/h、5:1／26mm が 27.44 km/h といった具合に、「換えたらどれくらいになるか」を並べて見られます。

ロックしたときに出る電圧別比較表とは別物です。あちらはタイヤ固定で「電圧 × ギヤ」、こちらは電圧固定で「ギヤ × タイヤ」です。ギヤを変えると実際の回転数も変わるので、この表の数字は「今の回転数のまま換えたら」の机上値です。

どれもロスなしの理論値です。実走の答えではありません。

必要トルクとジャンプの詳しくは、次の「逆算の必要トルクとジャンプ」を見てください。

逆算の「求めたいもの」に足した2つです。どちらも机上の計算で、実測ではありません。逆算を開くと最初に「あくまで机上の計算結果です」と出ます。「二度と表示しない」を押すと次から出ません。タイトルの横の「机上の計算結果」の印は常に出ています。

必要トルク mN・m

坂を一定速度で登り続けるのに、モーターにどれだけのトルクが要るかの見積もりです。選ぶと、入力は車重・坂の角度・タイヤ・ギヤだけになります。

  • 式は、車重 × 9.8 × sin(角度) × タイヤ半径 ÷ ギヤ比です。効率の割り引きは入れていません
  • 結果の下の小さい字が、ホイール側のトルクです
  • 坂だけ・一定速度だけの値です。加速、転がり抵抗、壁との摩擦は入っていないので、実際に必要な量はこれより大きくなります

結果の下でモーターを選ぶと、タミヤ公表の推奨負荷トルク（カタログ値）が出て、計算値がその範囲より小さいか・中か・超えるかを表示します。

  • 推奨負荷トルクは上限でも最大でもありません。カタログの回転数や電流を測るときの、負荷の目安です
  • 範囲より小さい … 想定より軽い負荷。カタログより高く回り、電流は少なめの側
  • 範囲の中 … 想定ど真ん中。カタログの値がだいたいそのまま目安になる
  • 範囲を超える … 想定より重い負荷。回転は下がり、電流と発熱は増える側。登れないという意味ではありません
  • ノーマルモーターは公表値がないので、その旨が出ます

選択欄の横の赤い？に、この比べ方の注意書きをまとめました。

ジャンプ（飛距離）

坂を登り切った先で、どれだけ飛ぶかの見積もりです。選ぶと、入力は回転数・坂の角度・坂の距離・落差・登り方の前提・射出角度・ギヤ・タイヤだけになります。

  • 入口の速度は、回転数・ギヤ・タイヤから出した机上速度です。アンペアと抵抗の補正は掛けません
  • 坂の距離は、坂の面に沿った長さ（cm）です。登る間にどれだけ速度が落ちるかの見積もりにだけ使います
  • 落差は、飛び出す点と着地点の高さの差（cm）です。着地が低い分をプラスにします。着地側は平らな前提です
  • 射出角度は任意です。空欄なら坂の角度と同じとして計算します。出口がカーブしている区間では、実際の飛び出す向きに近い数字を入れます

登り方の前提は、登る間の速度の落ち方をどちらで見積もるかです。横の？にも説明があります。

  • 惰性のみ … 車の運動エネルギーだけで登る前提。モーターの駆動の助けを数えないので、一番大きく落ちる側
  • 一定速度 … モーターの駆動が重力分を全部補って、速度が落ちない前提
  • どちらの前提でもモーターは回り続けます。実際の落ち方は、この2つの間です

結果は飛距離が大きく出て、その下に射出速度・浮遊時間・最高到達点・着地角度が出ます。惰性のみで登り切れない計算のときや、着地点の高さに届かないときは、数字ではなくその旨が出ます。車体を1つの点として扱い、空気抵抗・車体の回転・跳ねは入れていません。

RPM Memory estimates motor RPM from sound. Values are estimates and desk calculations. It is not a certified tachometer. Tap a heading to open it.

From the top: the name, the spectrum, the pickup window, MOTOR RPM, SPEED, status, and buttons.

CURRENT is the live value. AVG is the stable part of this run. MAX and MIN are the high and low of this run. With "count after stable" on, MAX, MIN and AVG start only after 8000 rpm has held for 0.6 seconds.

SPEED is a desk calculation from RPM, gear and tire. It is not track speed.

Start uses the microphone. Lock freezes the number for the chart and writes a lock memo. Save asks for a name and writes a measurement record. Reset clears only the live numbers.

History is the list of saved measurements. The lock memo in machine setup is a separate list of lock moments. They are not the same.

Reverse calc opens with the locked numbers, and you can still edit them. The item you solve for is greyed out.

Each card is a saved measurement, laid out as a small table. Row 1 is RPM and RPM average. Row 2 is speed and speed average. Row 3 is the tire-on figures (alone, then with tires) and the loss %. Row 4 is motor, voltage, gear and tire size. The top line holds the check, date, name and delete.

Filter and sort is closed until you tap it. Delete RPM 0 removes records whose RPM is 0. The button above the list exports all records as a CSV file. The motor graph button charts one motor's records over time (line colour = gear, point core = voltage band), with the change from the first to the latest record and per-record change vs the previous and the first record.

Set shaft, chassis, motor, voltage, gear, tire and load. Registering a setup asks for a name and stores voltage and running load too.

There is no name field here. The name is asked when you tap Save on the top screen. The name field inside the lock memo is only for that lock moment.

Reverse calc also solves for required torque and jump distance. Required torque estimates the motor torque needed to climb a slope at steady speed from weight, angle, tire and gear, and compares it with the catalog recommended load torque of the motor you pick. Jump estimates the flight distance from the desk entry speed, slope distance, drop and a climbing assumption (coasting only, or constant speed), with an optional launch angle. Both are desk calculations, not measurements. The matrix mode lists desk speeds for every gear x tire pair at the current RPM and voltage; tap a cell to set that gear and tire in the calculator.

In Settings, Export writes history, settings and favorites to one JSON file. Import replaces the current data with that file and reloads. The CSV button in History is only for viewing in a spreadsheet, not for restoring.

求めたいもの
比べられますが、同じものではありません。
・どちらもモーター軸トルク（mN・m）なので、この計算値（モーター軸に換算した値）とは直接比べられます。ホイール側トルクとは比べられません。
・計算で出るトルクは負荷側からの要求で、「この坂を登るにはモーターにこれだけ必要」という値です。推奨負荷トルクはモーター側の基準点で、タミヤが回転数・消費電流を公表するときの測定条件です。上限でも最大トルクでもありません。
・読み方：必要トルクが推奨範囲より小さい＝推奨点より軽い負荷／範囲内＝想定ど真ん中／超える＝推奨点より重く、回転が下がり電流と発熱が増える側（登れない、という意味ではありません）。
・この計算は坂・一定速度ぶんだけです。加速・転がり抵抗・壁摩擦は入っていないので、実際は余裕を見てください。

登り方の前提とは

坂を登ると、車は高さをもらう代わりに速度を失います。その「支払い」をどちらの前提で見積もるかの選択です。

惰性のみ：支払いは車が持っている運動エネルギー（＝惰性）だけが担当し、登っている間にモーターが新たに生む仕事は計算に入れません。一番大きく落ちる側の見積もりです。

一定速度：モーターの駆動が重力分を全部補って、速度が落ちない前提です。

どちらの前提でもモーターは回り続けます。「惰性のみ」はモーターが止まる意味ではありません。実際の落ち方は、この2つの間になります。
